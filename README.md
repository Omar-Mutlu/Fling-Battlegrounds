# Fling-Battlegrounds
A multiplayer fighting game made by Omar (6th grade, Virginia's 11th district) in Roblox Studio for the 2026 Congressional App Challenge.

## How to play
Click on another player or dummy, pick them up, and swing them in any direction to throw them off the map.

## How it was made
- Built in Roblox Studio (Luau)
- Uses Roblox's built-in Drag module in the starter character script and in the dummies
- Some buildings can be broken, but the rebuild feature is still glitchy
- I did not write original code yet. Next, I want to learn Roblox scripting.
